# B4 Course Rule

This file contains B4-specific rules that override generic Workflow A defaults when they conflict.

## Primary Lecture-Note Authority

- The only default B4 lecture-note authority layer is the Wilkinson slide family:
  - `sources/B4_Nuclear_Slides_(Wilkinson).mineru_api.md`;
  - `sources/B4_Scattering_Slides_(Wilkinson).mineru_api.md`; and
  - `sources/B4_Particle_Slides_(Wilkinson).mineru_api.md`.
- B4 retrieval is Markdown-first.
- Use the matching locator to route into the Markdown line ranges before reading the source itself: `sources/B4_Nuclear_Slides_(Wilkinson)_Locator.md`, `sources/B4_Scattering_Slides_(Wilkinson)_Locator.md`, or `sources/B4_Particle_Slides_(Wilkinson)_Locator.md`.
- The B4 Markdown locators collapse consecutive repeated slide titles into single runs and join clearly split heading fragments because the slide PDFs repeat titles page by page.

## Part Split

- Treat B4 as three operational parts: nuclear, scattering, and particle physics.
- Before retrieval, inspect the question against the B4 locator headings and source titles to decide which part or parts the question belongs to.
- If a question clearly belongs to one part, start there.
- If it spans more than one part, read only the relevant sections from each applicable part.

## Optional User-Note Layer

- This vault does not depend on a user-note layer.
- If the user supplies B4 notes, treat `<USER_TUTORIAL_ORDER_NOTES>` as the main optional companion unless the user explicitly says otherwise.
- Do not read separately supplied `<USER_TUTORIAL_NOTES>` by default in Workflow A.
- Read `<USER_TUTORIAL_NOTES>` only when the user explicitly asks for tutorials, asks for both note sets, or otherwise puts those notes in scope.

## Other Oxford Lecture-Note Resources

- Wascko and Viehhauser are opt-in resources, not default B4 lecture notes.
- Use them only when the user explicitly requests other lecture-note resources or names the source.
- Their opt-in MinerU precision-API Markdown artifacts and locators are:
  - `sources/B4_Nuclear_and_Particle.mineru_api.md`;
  - `sources/B4_Nuclear_and_Particle.mineru_api_Locator.md`;
  - `sources/B4_First_Steps_in_Subatomic_Physics_(Viehhauser).mineru_api.md`; and
  - `sources/B4_First_Steps_in_Subatomic_Physics_(Viehhauser).mineru_api_Locator.md`.
