# Exam Question Workspace

The original vault's exam-question files are omitted from this version. The folder structure and generic path references remain.

Use these generic forms:

- answer folder: `questions_and_answers/exam_questions/<course>/<paper>/`
- answer file: `questions_and_answers/exam_questions/<course>/<paper>/<paper>_Questions_and_Answers.md`
- source folder: `questions_and_answers/exam_questions_raw/<course>/<paper>/`
- source file: `questions_and_answers/exam_questions_raw/<course>/<paper>/<source-file>`
- workflow log: `questions_and_answers/exam_questions/<course>/<paper>/<paper>_Q<n>_Workflow_Log.md`
- source extracts: `questions_and_answers/exam_questions/<course>/<paper>/<paper>_Q<n>_Source_Extracts.md`

This directory is reserved for users to create and manage their own exam-question material. Follow `.claude/rules/exam_question.md` when adding new work.
