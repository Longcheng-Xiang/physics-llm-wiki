# How This Wiki Works — Durable Context

Last updated: 2026-04-28

## What The Vault Is For

- The vault is agent-maintained working memory for Oxford physics, designed to sit between raw sources and future answers.
- Human readability matters most in the top control docs. Deeper source artifacts should optimize for accurate routing and durable reuse.

## How Knowledge Should Accumulate

- Source maps, summaries, and locators exist to make the lecture-note authority layer easy to route into without reopening PDFs unnecessarily.

## Operational Stance

- The vault should prefer stable routing docs plus durable compiled memory over decorative structure or repeated instructions.
- When the agent deletes files by its own judgment during cleanup, it should tell the user what was deleted and give a short reason for each deleted group rather than reporting only that the cleanup happened.
