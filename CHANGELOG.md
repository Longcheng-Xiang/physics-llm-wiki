# Changelog

This file records changes made in official releases of the Physics LLM Wiki. It is separate from `log.md`, which records substantive changes made while operating an individual copy of the vault.

## 1.0.0 - 2026-10-19

- Established the first versioned release of the vault.
- Retained lecture-note routing and exact local source paths while leaving original PDFs, complete conversions, and conversion assets for users to supply locally.
- Added non-commercial licensing terms for original software and original non-software content.
- Added repository-wide ignore rules for credentials, user-supplied source documents, local application state, dependencies, caches, and generated build output.
- Added the Physics Wiki viewer source and an application build for Apple Silicon Macs running macOS 11 or later.
- Added an untested Windows 11 x64 viewer preview.
- Refreshed viewer dependencies and rebuilt both application packages after the pre-release security audit.
